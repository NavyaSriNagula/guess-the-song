# 🎵 Lyric Match  

## ⭐ Features  
AI-generated song lyric snippets using Gemini AI. 30-second countdown timer with 3 chances to guess the correct song title.  

---

## 🚀 How to Run Locally  
1. Clone the repository:  
   `git clone https://github.com/NavyaSriNagula/guess-the-song.git`
   Open the project folder 

3. Backend Setup:  
   - Navigate to the backend directory: `cd backend`  
   - Install dependencies: `npm install`  
   - Create a `.env` file in the `backend/` folder with:  
     ```
     GEMINI_API_KEY=your-gemini-api-key
     PORT=5000
     ```  
   - Start the backend: `npm start`  

4. Frontend Setup:  
   - Navigate to the frontend directory: `cd frontend`  
   - Install dependencies: `npm install`    
   - Start the frontend: `npm run/ npm start`  

5. Open the frontend in your browser:  
   `http://localhost:3000`
